# SKYRAIL — The Iron Run

Запускаемая браузерная 3D-игра от третьего лица. Ограбление воздушного конвоя, паркур, магнитный трос и бой на независимо движущихся платформах. Все игровые модели, материалы, анимации, облака, эффекты и звук создаются локально. Для игры не нужны аккаунты, API-ключи или доступ к интернету.

## Запуск

На этом компьютере: двойной щелчок по **PLAY-SKYRAIL.cmd**. Оставьте окно сервера открытым и играйте в Chrome или Edge по адресу **http://127.0.0.1:4177**.

Альтернатива из этой папки:

```sh
node server.cjs
```

Нужны Node.js 22+ и браузер с WebGL2 и аппаратным ускорением. `npm install` для запуска не требуется: Three.js включён в `vendor/`. Не открывайте `index.html` через `file://`: браузеры блокируют локальные ES-модули. Если порт занят другой программой, задайте переменную `PORT` перед запуском.

## Первые минуты

Нажмите **NEW RUN**, затем **E**, чтобы спрыгнуть с дельтаплана и зацепиться за последний вагон. Двигайтесь к голове состава, отключите три индукционных замка и победите охотника у локомотива. **F** рядом с генератором отключает его; генераторы также можно расстрелять или вырвать режимом RIP. **F** у локомотива после выполнения целей открывает выбор улучшения и следующего маршрута.

После четырёх участков появляется **The Admiral**. Уничтожайте подсвеченные системы последовательно: турбины → генераторы щита → сердечник. В финале зацепитесь за красный поезд слева впереди, **приземлитесь на него** и нажмите **F**.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | Движение относительно камеры |
| Мышь | Обзор после щелчка по игровому полю; альтернативно удерживайте ПКМ |
| Стрелки | Обзор без захвата мыши |
| Shift | Спринт; в настройках можно включить переключение |
| Space | Прыжок, второй прыжок, прыжок от стены |
| Ctrl | Скольжение / приседание; у боковой рейки — grind |
| C | Воздушный рывок |
| E | Зацепиться / отпустить магнитный трос |
| Q | Переключить PULL / SWING / SLINGSHOT / DRAG / RIP / LINK |
| Удержать E → отпустить | Зарядить и выполнить SLINGSHOT |
| ЛКМ | Стрелять |
| 1–5 | Выбрать оружие |
| R / X | Перезарядка / удар ногой |
| F | Генераторы, тайники, маршрут, эвакуация |
| Esc / H | Пауза / руководство |

Режимы DRAG/RIP/LINK сначала ищут врага впереди, затем подходящий объект рядом. RIP снимает щит тяжёлого противника. LINK связывает цель с ближайшим другим транспортом. В SWING трос ограничивает расстояние до движущейся точки, сохраняя тангенциальную скорость. Отпускайте E и продолжайте прыжок. При падении ещё можно зацепиться за транспорт; ниже зоны спасения автоматически срабатывает аварийный трос с потерей здоровья.

## Содержимое

- Четыре последовательных участка конвоя и отдельная арена босса с тремя фазами и эвакуацией.
- Основной и параллельный составы, верхние грузовые платформы, воздушные корабли, подвесная инфраструктура и тайники.
- Шесть визуальных тематик: Iron Run, Cloud City, Scrap Fields, Sun Temple, Storm Belt, Undercloud. Маршрут выбирается после участка.
- Пять видов оружия с разными импульсами, электрическими цепями, взрывами, магазинами и перезарядкой.
- Семь ролей противников; щиты, перелёты, прыжки между транспортом, снайперские предупреждения и развёртываемые турели.
- 24 модификации забега, постоянная мастерская, база, выбор начального оружия.
- Погода, ветер, многослойные облака, искры, электрические тросы, взрывы, дым, пространственный звук и адаптивная процедурная музыка.
- Четыре качества графики, масштаб рендера, тени, облака, частицы, FOV, чувствительность, сила отклика камеры, громкость трёх каналов и полноэкранный режим.

Детали мастерской, покупки и рекорды сохраняются в localStorage текущего браузера. Продолжение и повтор после поражения начинаются **с начала текущего участка**, с выбранными модификациями. Инкогнито и другой браузер используют отдельные сохранения.

## Проверки

Сервер должен быть запущен. Для браузерных тестов нужен Playwright и установленный Chrome. Playwright закреплён в devDependencies; на другом компьютере установите инструменты тестирования командой `npm install`. Это не требуется для самой игры.

```sh
node tests/physics.test.mjs
node tests/playtest.cjs
node tests/ui.cjs
node tests/pilot.cjs
node tests/capture.cjs
node tests/benchmark.cjs
```

Физические тесты проверяют устойчивость на движущейся опоре, перенос скорости при прыжке, контакт с платформой, ограничение прыжков, рывки, движущиеся точки троса и одинаковую траекторию при разных частотах отрисовки. Браузерные сценарии проверяют оружие, режимы троса, укрытия, сохранение, мастерскую, маршруты, босса и интерфейс. Отчёты находятся в `test-results/`, кадры — в `screenshots/`.

`pilot.cjs` выполняет ускоренное прохождение через производственный контроллер и обычные игровые действия. Он не телепортирует персонажа, не меняет здоровье и не уничтожает цели напрямую; **прицеливание автоматическое и точное**. Это проверка проходимости, а не человеческий плейтест или замер длительности.

## Устройство и границы версии

`physics.js` — фиксированный шаг 120 Гц и скорости относительно опор; `world.js` — локальные координаты транспорта и точек крепления; `combat.js` — оружие, попадания и противники; `game.js` — камера, управление, прогресс и сохранения; `assets.js` — модели и анимации; `atmosphere.js` и `audio.js` — изображение и звук; `ui.js` — интерфейс.

Это первая полностью проходимая версия, а не подтверждённый релиз студийного масштаба. Тематические участки используют общую структуру конвоя. Анимации процедурные, навигация противников локальная, разрушения ограничены интерактивными объектами и эффектами, динамика корабля постановочная. Нет полного физического разрушения каждого ограждения, сложной IK и уникального набора архитектуры для каждого маршрута. Заявленная в исходном задании длительность **20–40 минут не подтверждена человеческим плейтестом**. Подробности создания графики — в `ART.md`.
