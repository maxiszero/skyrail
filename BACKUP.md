# Снимок SKYRAIL

Этот репозиторий содержит текущую первую проходимую сборку игры. Запуск и управление описаны в [README.md](README.md), результаты проверок и ограничения — в [VALIDATION.md](VALIDATION.md).

- В корне: весь исходный код, локальная Three.js с лицензией, тесты и документация.
- `artifacts/SKYRAIL.zip`: готовый архив для локального запуска.
- `artifacts/screenshots/`: все сохранённые скриншоты игры и интерфейса.
- `artifacts/validation/`: сохранённые результаты проверок, включая два финальных автоматических прохождения. `pilot-before-cover-response.json` — промежуточный исторический результат, актуальный — `pilot.json`.

Источник: локальный коммит `e391c54bdc52bf840b7bc3d488577e5d6fb7558c`, каталог `skyrail`. Зависимости для разработки восстанавливаются через `npm ci`; для запуска игры установка зависимостей не требуется.
